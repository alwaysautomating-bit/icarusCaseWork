# Transcript Archive

This folder retains material that should leave the active workflow without being deleted.

- `processed-inputs/` receives successfully processed inbox originals.
- `experiments/` contains superseded tools, test runs, and generated outputs.
- `review-required/` retains conflicting or ambiguous source candidates without changing the canonical preserved source.
- Derived notes that are based on transcripts but are not transcript sources may be retained here with their role clearly identified.

Archive contents are historical inputs or implementation evidence. They are never selected by the active processor or canonical Supabase publisher.
